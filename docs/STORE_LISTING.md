# Chrome Web Store listing

Everything the [developer dashboard](https://chrome.google.com/webstore/devconsole) asks for, ready to paste. Images are
generated by `pnpm --filter @pr-sift/capture cards` into `media/store/`.

## Before the first upload

1. Register a developer account (one-time fee) and turn on 2-step verification for that Google account.
2. Merge to `main` so the site and the privacy page are live.
3. `pnpm package` and upload `apps/extension/pr-sift-<version>.zip`.

## Store listing tab

**Summary** comes from `description` in `manifest.json` (124 of 132 characters).

**Description**

```text
PR Sift opens a focused review on top of any GitHub pull request, so a 200-file change becomes the 12 files that matter.

Filter the noise
• Click a file type or change to show only that, shift-click to hide it on every pull request.
• Combine filters: .php and added shows only new PHP files.
• Smart filters for tests, migrations, translations, config and CI.

Track what you read
• Mark files or whole folders as viewed and hide them.
• A ring shows what is left. Files changed by a new push come back.

Private notes
• Write notes on one or many lines while you review. They stay in your browser.
• Self-review code your AI wrote, or keep side notes during a team review.
• Copy all open notes for Claude, ChatGPT or Gemini as one prompt with the code.
• Post a note to GitHub as a review comment only when you choose.

Read it your way
• Unified or split diffs, for every file or just one.
• Light, dark or system theme with GitHub's diff colors.

Free and open source (MIT). No account, no server, no analytics. PR Sift only talks to GitHub.

Not affiliated with GitHub.
```

## Privacy tab

**Single purpose**

```text
Helps people review large GitHub pull requests: filter changed files, track viewed files and keep private notes on the Files changed page.
```

**Permission justifications**

| Permission                                   | Justification                                                                                 |
| -------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `storage`                                    | Saves settings, viewed files and private notes locally in the browser.                        |
| `https://github.com/*`                       | Shows the review on pull request pages and reads the pull request diff with the user's login. |
| `https://patch-diff.githubusercontent.com/*` | GitHub redirects some diff downloads to this host.                                            |
| `https://api.github.com/*`                   | Only with a user-added token: reads large diffs and posts a note as a review comment.         |

**Remote code:** No, all code is in the package.

**Data usage:** tick **Authentication information** only. The optional GitHub token is stored in `chrome.storage.local`
and sent only to `api.github.com`. Then tick all three certifications (not sold, not used for unrelated purposes, not
used for creditworthiness).

**Privacy policy URL:** https://haythamasalama.github.io/pr-sift/privacy/
