# Chrome Web Store listing

Everything the [developer dashboard](https://chrome.google.com/webstore/devconsole) asks for, ready to paste. Images are
generated by `pnpm --filter @pr-sift/capture cards` into `media/store/`.

## Before the first upload

1. Register a developer account (one-time fee) and turn on 2-step verification for that Google account.
2. Merge to `main` so the site and the privacy page are live.
3. `pnpm package` and upload `apps/extension/pr-sift-<version>.zip`.

## Store listing tab

**Summary** comes from `description` in `manifest.json` (130 of 132 characters).

**Description**

```text
Review big GitHub pull requests without the noise. PR Sift opens a focused review on top of any pull request, so a 214-file change becomes the 12 files that matter.

Write notes. Your AI fixes them.
• Write private notes on any lines while you review. They stay in your browser.
• Copy every open note as one prompt, with file, lines and code, for Claude Code, Codex, Cursor or GitHub Copilot, or open it in Claude or ChatGPT.
• Resolve what got fixed, or post a note to GitHub as a review comment in one click.

Merge without AI co-authors
• Approve, request changes and merge from the review, with the merge method you choose.
• When you squash, Claude, ChatGPT, Gemini, Copilot and other AI tools start unchecked, so they stay out of your history unless you keep them.
• The people you uncheck stay unchecked next time.

Show only the files you want
• Click a file type or a change to see only those files. Shift-click hides it on every pull request.
• Open or close whole folders, or jump to tests, migrations, translations, config and CI.
• Save the filters you use as a button in the top bar.

Never read a file twice
• Mark files or whole folders as viewed and they leave the list. The ring shows what is left.
• Files changed by a new push come back on their own.

Everything else in one place
• GitHub comment threads under their lines, and the conversation above the files.
• Unified or split diffs, for every file or just one.
• The pull request description one click away.
• Light, dark or your system's theme, with GitHub's colors.
• Open every pull request straight in PR Sift, if you want.

Private by design
Free and open source (MIT). No account, no server, no analytics. PR Sift talks only to GitHub. A GitHub token is optional and only needed to approve, comment and merge from the review.

Not affiliated with GitHub.
```

## Privacy tab

**Single purpose**

```text
Helps people review large GitHub pull requests: filter changed files, track viewed files, keep private notes, and review or merge from the Files changed page.
```

**Permission justifications**

| Permission                                   | Justification                                                                                   |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `storage`                                    | Saves settings, viewed files and private notes locally in the browser.                          |
| `https://github.com/*`                       | Shows the review on pull request pages and reads the pull request diff with the user's login.   |
| `https://patch-diff.githubusercontent.com/*` | GitHub redirects some diff downloads to this host.                                              |
| `https://api.github.com/*`                   | Only with a user-added token: reads large diffs and comments, approves, merges and posts notes. |

**Remote code:** No, all code is in the package.

**Data usage:** tick **Authentication information** only. The optional GitHub token is stored in `chrome.storage.local`
and sent only to `api.github.com`. Then tick all three certifications (not sold, not used for unrelated purposes, not
used for creditworthiness).

**Privacy policy URL:** https://pr-sift.haythamasalama.me/privacy/
