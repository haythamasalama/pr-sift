# Changelog

## 0.1.0

First public release.

- Review workspace on top of GitHub pull requests, reading with the signed-in session.
- Smart filters: file types, status, categories, recurring folders, folders by parent.
- Review mode with progress ring and content-based viewed marks.
- Folder tree with expand/collapse all, resizable sidebar and responsive drawer.
- Unified and split diffs (global and per file) with syntax highlighting.
- Private notes, copy-for-assistant prompt, and posting a note as a GitHub comment.
- Live update detection with in-place refresh.
